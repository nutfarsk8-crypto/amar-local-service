আমার স্থানীয় সেবা কেন্দ্র — Income / Money Making Version

এই ভার্সনে যোগ হয়েছে:
- Featured Local Businesses / Sponsored Listing
- Basic ₹100/মাস, Premium ₹300/মাস — উদাহরণমূলক প্যাকেজ
- “বিজ্ঞাপন দিতে যোগাযোগ করুন” WhatsApp flow
- AdSense-এর জন্য বিজ্ঞাপনের placeholder জায়গা
- সার্চে Featured Business-ও খুঁজে পাওয়া যাবে
- আগের জরুরি সেবা, স্থানীয় সেবা, বাজার, হেল্পলাইন ও নোটিশ সুবিধা রাখা হয়েছে

সবচেয়ে গুরুত্বপূর্ণ সেটিং:
app.js ফাইলের একদম উপরে:
ownerWhatsApp = "91XXXXXXXXXX"
এখানে আপনার WhatsApp নম্বর বসাবেন। Country code সহ লিখবেন, + চিহ্ন ছাড়া।
উদাহরণ: 919876543210

ownerPhone-এ চাইলে আপনার ফোন নম্বর দিতে পারেন।

স্থানীয় ব্যবসার পেইড লিস্টিং:
featured array-তে নাম/বিবরণ/মূল্য পরিবর্তন করে আপনার নিজের প্যাকেজ বানাতে পারবেন।
কোনো ব্যবসা টাকা দিয়ে লিস্টিং নিলে তাদের নাম, ফোন, ঠিকানা, ছবি ইত্যাদি এখানে যোগ করুন।

AdSense:
এই প্যাকেজে কোনো ভুয়া AdSense publisher code দেওয়া হয়নি। Google AdSense account/site approval পাওয়ার পরে Google থেকে পাওয়া আসল বিজ্ঞাপন কোড HTML-এর উপযুক্ত জায়গায় বসাতে হবে।

নিরাপত্তা:
কখনোই GitHub token, API key, password বা private credential ওয়েবসাইটের JavaScript-এ রাখবেন না।

GitHub Pages:
ফাইলগুলো repository-এর publishing source-এ upload/replace করে Commit changes করুন। GitHub Pages-এ পরিবর্তন প্রকাশ হতে কয়েক মিনিট সময় লাগতে পারে।

প্রকাশের আগে:
- স্থানীয় ফোন নম্বর যাচাই করুন
- ব্যবসার মালিকের অনুমতি নিয়ে paid listing দিন
- জরুরি নম্বর যাচাই করুন
- ভুল/ভুয়া তথ্য প্রকাশ করবেন না
